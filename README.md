# cogame-poker — merged into cogame-cosino

This repo is archived. OS Poker's ladder (Kuhn → Leduc → no-limit Hold'em
heads-up → six-max) was merged into
[cogame-cosino](https://github.com/Metta-AI/cogame-cosino) on 2026-08-26 as
variants of one game, alongside cosino's classic chip-race tables
(cogame-cosino#1). Poker was originally forked from the cosino scaffold; the
merge reunites them.

- Code, CI, releases: <https://github.com/Metta-AI/cogame-cosino>
- Watch it: <https://softmax.com/cosino>
- The Poker league on softmax.com is retired; submit policies to the Cosino
  league instead. A policy is still just a prompt: reuse the published cosino
  player runnable and set `PLAYER_PROMPT`.
